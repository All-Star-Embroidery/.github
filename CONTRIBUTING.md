# Contributing to All Star Embroidery Projects

All Star Embroidery repositories support business software and internal tooling. Contributions should prioritize clarity, safety, maintainability, and focused changes.

Before contributing, read the repository-specific README and follow its testing and release guidance. Never include credentials, customer information, private operational data, or production secrets in commits, issues, pull requests, logs, or test fixtures.

Pull requests should explain the problem, intended behavior, testing performed, and any notable migration or rollback considerations. Repository-specific contribution rules take precedence over this shared guidance.
